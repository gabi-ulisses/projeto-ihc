# 🧩 [IHC: Usabilidade e Acessibilidade](https://gabi-ulisses.github.io/projeto-ihc)

"IHC: Usabilidade e Acessibilidade" é um projeto desenvolvido como trabalho final da disciplina de **Introdução ao Desenvolvimento de Páginas Web** (Tecnólogo em Sistemas para Internet). 

Tendo como objetivo criar experiências web que funcionam para todos, buscamos implementar um **Manual de Acessibilidade** contido por dicas e exemplos de uso em nosso cotidiano.

Para desenvolvimento do projeto, utilizamos tecnologias como **HTML** e **CSS**.

- Página inicial com informações sobre o projeto;
- Página de dicas de acessibilidade web;
- Design responsivo para diferentes dispositivos.

## 🤝 **Como Contribuir**

Se você deseja contribuir para o desenvolvimento deste projeto, siga os passos abaixo:

1. Faça um fork deste repositório.
2. Crie uma nova branch: `git checkout -b minha-branch`.
3. Faça suas alterações e commit: `git commit -m 'Minhas alterações'`.
4. Envie para o repositório remoto: `git push origin minha-branch`.
5. Abra um Pull Request.
